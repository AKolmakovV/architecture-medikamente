## Общие, организационные меры защиты

1. Разработка и внедрение политик информационной безопасности
2. Регулярное обучение и повышение осведомленности сотрудников
3. Введение режима коммерческой тайны (для коммерческих данных)
4. Подписание NDA с сотрудниками и контрагентами

## Общие, технические меры

1. Многофакторная аутентификация Keycloak
2. KeyCloak  RBAC для доступа к данным по принципу минимального доверия
3. Внедрение SIEM и DLP системы
4. Шифрование дисков, и базы данных (PostgreSQL pgcrypto)
5. Групповые политики и настройка внутридоменного взаимодействия
6. Регулярное резервное копирование с шифрованием дисков
